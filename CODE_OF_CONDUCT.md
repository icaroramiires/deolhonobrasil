# Código de conduta

Este projeto discute dinheiro público e pessoas no exercício de função pública. A conversa técnica e as contribuições seguem três regras.

1. Crítica ao código, ao método e ao dado. Sem ataque a quem contribui e sem uso da plataforma para campanha contra uma pessoa.
2. Linguagem sem acusação automática. O mesmo padrão de `assert_non_accusatory_language` vale para issue, pull request e texto de interface.
3. Dado pessoal só entra quando for necessário para compreender o gasto público já publicado por fonte oficial, e CPF de pessoa física comum permanece mascarado.

Pedido de ajuda e relato de conduta vão pelo canal indicado em `SECURITY.md` quando envolverem segurança, ou pelos mantenedores do repositório nos demais casos. Mantenedor que participar do fato não decide sozinho a medida.

Este texto é próprio do projeto. Não incorpora o texto integral de outro código de conduta.
