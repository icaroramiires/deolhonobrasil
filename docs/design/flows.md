# Jornadas e fluxos

## 1. Pesquisa e consulta de despesa

Início → termo de busca → sugestões por tipo → resultados agrupados → filtros → despesa → fonte original.

- Manter filtros ao retornar.
- Sem resultados: sugerir correção, remoção de filtros e temas próximos.
- Fonte indisponível: manter metadados, informar última consulta e permitir acompanhar.

## 2. Investigação de contrato

Contratos → filtro por objeto/fornecedor/órgão → seleção → resumo → linha do tempo → documentos → relação em tabela.

- Alterações contratuais não devem ser tratadas automaticamente como suspeitas.
- Valores devem identificar inicial, atualizado e pago.
- Documento ausente reduz completude e limita conclusões.

## 3. Verificação de análise

Análises → tipo de sinal → detalhe → método → evidências → limitações → revisão humana → contestação.

- Estado inicial nunca usa linguagem acusatória.
- Toda conclusão deve registrar autor/revisor, data e versão.
- Contestação gera protocolo e não remove silenciosamente o conteúdo anterior.

## 4. Acompanhamento

Busca/entidade/detalhe → Acompanhar → escolher eventos e frequência → confirmar → gerenciar em Acompanhamentos.

Eventos: novo documento, alteração de valor, novo pagamento, nova análise ou resposta a contestação.

## 5. Contribuição cidadã

Contexto → Contribuir → categoria → descrição → anexos → revisão de dados pessoais → envio → protocolo → acompanhamento.

- Exibir finalidade e política de privacidade antes do envio.
- Permitir salvar rascunho autenticado.
- Arquivos passam por validação de formato, tamanho e segurança.

## 6. Revisão administrativa

Fila → prioridade e motivo → comparação entre fontes → decisão → justificativa → publicação → auditoria.

Decisões: aprovar, solicitar complemento, rejeitar, despublicar temporariamente ou encaminhar para especialista. Toda ação é registrada.

## Erros globais

- Conexão: preservar entradas e oferecer nova tentativa.
- Permissão: explicar requisito e ação seguinte.
- Dados incompletos: mostrar campos conhecidos e lacunas.
- Fonte fora do ar: informar que a falha é externa.
- Conflito de atualização: impedir sobrescrita silenciosa.
