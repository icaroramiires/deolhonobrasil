# Governança de código aberto

## O que já está no repositório

| Artefato | Função |
| :--- | :--- |
| `LICENSE` | Código sob AGPL-3.0-or-later. Dados derivados sob CC-BY-4.0 com atribuição e proveniência. Marca fora das duas licenças |
| `CONTRIBUTING.md` | Contribuição técnica e editorial |
| `SECURITY.md` | Divulgação de vulnerabilidade |
| `TRADEMARK.md` | Nome De Olho no Brasil separado do código |
| `.github/pull_request_template.md` | Pedido de revisão |

## O que a licença não faz

A AGPL obriga disponibilização do código correspondente quando uma versão modificada é oferecida pela rede. Ela não transfere a marca, não licencia dado de terceiro além do que a fonte permite e não reduz responsabilidade civil por conteúdo.

## Contribuições

Não há CLA nem cessão obrigatória de direito autoral. O desenvolvedor de cada patch mantém seus direitos e licencia a contribuição nos termos do arquivo `LICENSE` ao enviá-la. Um DCO de uma linha pode ser adotado depois, se a comunidade quiser rastrear a declaração do autor. Esta alteração não o institui.

Mudança sensível — esquema, RLS, regra que acusa indiretamente uma pessoa, política de publicação ou custo de infraestrutura — precisa de especificação e revisão. Não entra só porque o teste local passou.

## Conflito de interesse

Quem revisar um dossiê declara, no registro humano que ainda cabe operacionalizar, vínculo com o órgão, o fornecedor ou a pessoa citada. O software ainda não tem campo obrigatório para essa declaração.

## Marca

Uso do nome e do logotipo segue `TRADEMARK.md`. Fork público troca o nome da instância.

## Modelos

Pesos de terceiros, se forem adicionados, entram com a licença do autor do modelo e com hash do arquivo. Não estão neste commit.
